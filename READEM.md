# K-SIWAP Streamlit Hackathon Starter

## Run locally
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`.
4. Run `streamlit run app.py`.

## What's included
- Student profile and simple explainable job matching
- Skill-gap list, demo application tracker, mock interview prompts
- Job fair listings and interest registration (demo only)
- Employer job draft preview
- District/state job-demand charts using synthetic demo records
- CSV/Excel upload preview, schema checks, missing-value checks, CSV export
- Safeguards and Render deployment notes

## Important
All built-in job and analytics records are synthetic demonstration data. Replace them with verified, documented datasets before making real-world claims. This starter does not provide authentication, persistent database storage, real notifications, CV parsing, or live job submissions.
